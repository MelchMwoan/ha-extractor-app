# Home Assistant Dashboard Extractor

A Home Assistant app that allows you to record your Home Assistant dashboards as animated webp or mp4 files. Useful when the HA framework is too heavy to load on your old devices, or if you want to use the extracted dashboard as a screensaver on your TV.

## Installation
[![Open your Home Assistant instance and show the add app repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FMelchMwoan%2Fha-extractor-app)

1. Add the repository to your Home Assistant instance:
```
https://github.com/MelchMwoan/ha-extractor-app
```
2. Install the app
